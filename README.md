# JobNest

JobNest is a React/Vite application with an Express/MongoDB API and Gemini powered AI tools.

## Deploy to Render

The included `render.yaml` configures a single Node web service. It builds the Vite site and serves it from Express, so the frontend and `/api` endpoints share one public URL.

1. Push this project to a GitHub repository. Ensure `backend/.env` is not committed; it is ignored by Git.
2. Create a MongoDB Atlas database and allow network access from Render. For a quick setup, Atlas can allow `0.0.0.0/0`; use a database user with a strong, unique password.
3. In Render, choose **New → Blueprint**, connect the repository, and apply the `render.yaml` configuration.
4. When prompted, enter `MONGO_URI` (the Atlas connection string) and `GEMINI_API_KEY` (from Google AI Studio). Render generates `JWT_SECRET` automatically.
5. Wait for the first deploy, then open the Render service URL. `/healthz` should return the API status message, and `/` should load JobNest.

The Blueprint uses Render's free web service plan. Free services may sleep when idle and take a little time to wake. Check Render's current plan details before relying on it for continuous availability.

## Required production settings

| Variable | Purpose |
| --- | --- |
| `MONGO_URI` | MongoDB Atlas connection string |
| `JWT_SECRET` | Signing key for login tokens; generated by the Blueprint |
| `GEMINI_API_KEY` | Gemini API key for AI assistant features |
| `GEMINI_MODEL` | Optional model override; defaults to `gemini-3.5-flash-lite` |
| `NODE_ENV` | Set to `production` by the Blueprint |
| `VITE_API_URL` | Set to `/api` by the Blueprint for same-origin API requests |

Do not commit API keys, MongoDB credentials, or `.env` files. If a credential was ever committed or shared publicly, rotate it before deployment.

## Run locally

Install the frontend dependencies with `npm install` and the backend dependencies with `npm install --prefix backend`. Put `MONGO_URI`, `JWT_SECRET`, and (for AI features) `GEMINI_API_KEY` in `backend/.env`. Start the API with `npm run dev --prefix backend`, then start Vite with `npm run dev` in another terminal.
